# Portfólio de Raul Guimarães Prestes

Portfólio pessoal desenvolvido com HTML, CSS e design responsivo.

## 📋 Características

- ✨ Design elegante com paleta de cores em tons de roxo e ouro
- 📱 Totalmente responsivo (mobile, tablet, desktop)
- 🎨 Fonte cursiva "Great Vibes" para o título principal
- 🧭 Navegação fixa no topo com efeito hover
- ⚡ Sem dependências externas (apenas Google Fonts)

## 📂 Arquivos

- `index.html` - Estrutura HTML da página
- `styles.css` - Estilos CSS com responsividade
- `README.md` - Este arquivo

## 🖼️ Imagens Necessárias

Coloque os seguintes arquivos PNG na raiz do projeto:

- `anjo.png` - Anjo decorativo do hero
- `outro-outro-anjo.png` - Anjo dentro da catedral
- `catedral.png` - Imagem da seção de apresentação
- `ankh.png` - Símbolo Ankh (Java)
- `toth.png` - Símbolo Toth (SQL)
- `corvo.png` - Imagem do projeto
- `anubis.png` - Anúbis (contato)
- `favicon.ico` - Ícone da página (opcional)

## 🔧 Personalização

### Cores
Edite as variáveis CSS em `styles.css`:

```css
:root {
  --ink: #150a22;
  --violet-deep: #2c0f4d;
  --violet: #5d1fa3;
  --violet-mid: #8a3fd6;
  --violet-bright: #9a54e0;
  --lavender: #d9c2f5;
  --parchment: #f4eefa;
  --gold: #c9a25a;
  --gold-soft: #e3c98a;
}
```

### Links Sociais
Edite em `index.html` as URLs do LinkedIn e GitHub:

```html
<a href="https://www.linkedin.com/in/seu-usuario">LinkedIn ↗</a>
<a href="https://github.com/seu-usuario">GitHub ↗</a>
```

## 🚀 Como Usar

1. Clone o repositório
2. Adicione as imagens PNG na raiz do projeto
3. Abra `index.html` no navegador
4. Personalize o conteúdo e os links
